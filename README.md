# AutoTextbook - AI自动教材生成工具

> 2026 Qoder 高校创造力大赛参赛作品

## 项目简介

AutoTextbook 是一个基于 AI 大模型的自动教材生成工具，旨在帮助教师和教育工作者快速生成高质量的教学材料。

## 功能特点

- 根据主题/大纲自动生成教材内容
- 支持多种学科和学段
- 智能排版和格式化
- 可导出为多种格式（PDF、Markdown等）

## 技术栈

- 前端：React + TypeScript
- 后端：Node.js
- AI：大语言模型 API
- 部署：Qoder Sites

## 快速开始

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build
```
